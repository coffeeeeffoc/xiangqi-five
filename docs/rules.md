# 规则、练习与电脑对手

以下页面和键盘操作描述 H5；原生 Canvas 采用固定 44 px 棋格与单指拖动。规则、存档、题目和电脑搜索共用同一份模块。

## 六题入门，两手连招

首页“60 秒练一题”直接进入下一道未完成练习，也可在玩法选择页从“战术闯关”自由选题。前五题分别练习车的补线、马腿、象眼、炮架、兵可后退：都要用红方一步连成五枚。第六题练习防守，走一步消除黑方下一手的全部五连威胁；支持吃掉威胁与截断车路等多个正确解法。棋池已用完，不能再抽子，吃将本身不会判赢。

两道进阶题是真正的红—黑—红：第一题先填十字交点，黑方拆掉一条线后，红方用另一条线成五；第二题先用炮架吃将，再接线成五，也接受帅先吃将的替代计划。红方最多行棋两次，黑方从全部合法走法中选择让红方下一手胜着最少的应手，优先吃子；不会用固定答案放行或让黑方空过。当前回应会显示在第二手目标中，所有合法成五解法都算完成。练习刷新会重新摆题。

非法走法不消耗机会；达到行棋次数却未完成目标会给出原因并允许立即重试。独立完成获两颗星，使用提示获一颗星，可重练提升记录；选题页显示入门/连招完成数与 16 星目标，结算给出下一题目标和“邀朋友解这题”。练习进度使用独立本机存档，兼容原六题记录；原单人或同屏棋局与已抽出的棋子会保留，“返回棋局”恢复。练习不计入好友排位；在好友房间中不能进入练习。

首页“分享游戏”和普通棋局的分享只发送游戏地址；战术练习的“分享当前关卡”与结算邀请优先使用系统分享，否则复制干净的网页链接；复制不可用时可手动选中复制。结算邀请按实际是否完成显示邀请文案，链接不含成绩。链接只含公开题目 ID，例如 `?challenge=cannon-link`，支持 GitHub Pages 子路径，不携带房间、服务地址、账号或凭证。八个合法 ID 为 `rook-bridge`、`horse-leg`、`elephant-eye`、`cannon-link`、`pawn-return`、`break-threat`、`crossroads`、`cannon-cross`；重复或未知 ID 不会装载局面。战术练习同时用于 H5 与父仓库的原生 Canvas 单机入口，不参与好友排位。

## 玩法（自由部署版）

- 可选 9×10 象棋棋盘或 15×15 五子棋棋盘。象棋棋盘显示楚河汉界，仅作标识、不影响走法；五子棋棋盘不显示。空盘红先黑后，各有车2、马2、相/象2、士2、帅/将1、炮2、兵/卒5。已有棋局切换尺寸时需确认重开。
- **部署：** 从剩余的实体棋子中等概率抽取一枚，必须放到任意空点。抽到后不能取消、重抽或改为移动；落子即换手。
- **快捷上场：** 未选中棋子时，可直接点击空位随机抽子并部署；也可先抽子查看。选中己方棋子后，点击目标位置仍按原规则移动。非法位置不会消耗棋池，同屏和联机使用同一规则。
- **胜负提示：** 获胜连线以金色连线和棋子光环标出，棋盘上方持续显示胜者与「再来一局」入口；同屏可直接重开，好友房间仍需双方同意。
- **移动：** 选择己方棋子，按其走法移动一次，可吃敌子。己方棋子不能互吃，被吃的棋子不回池。
- 车沿横竖直线走；马走日并检查马腿；象走田并检查象眼；士斜走一步；将帅横竖一步；炮不吃子时同车，吃子时须隔恰好一子。
- 取消九宫、象不过河、将帅照面、将军和将死；无飞将吃子。将帅被吃不直接判负。
- 兵卒可向前、向后、向左、向右走一步，没有方向或过河限制。
- 每次部署或移动后，任意种类己方棋子横竖斜连续 **至少五枚**，立即获胜。超过五枚也算。
- 棋池抽完仍能移动。轮到一方时无任何合法行动则和棋。没有自动重复局面判和，双方可协商重新开局。

点击己方棋子可查看合法落点，绿色点可走、红色虚线圈可吃。键盘 Tab 一次进入或离开棋盘，方向键在交叉点间移动，Enter / 空格选择；Home / End 移至当前行首尾，Ctrl + Home / End 移至整盘首尾，Esc 取消走子选择（不能取消已抽出的棋子）。落子动画或电脑思考后恢复原落点的焦点，可连续用键盘行棋；等待期间转到其他控件则保留新的焦点。说明页支持 Esc 或返回按钮回到上一页。

单人挑战由玩家执红先行，电脑执黑，双方遵守同一规则和随机棋池。可从对局“更多 → 调整玩法与难度”选择 **简易 / 标准 / 困难**，无需重开，刷新后保留难度；旧的入门/策略存档分别沿用简易/标准。

三个难度都会优先连五、阻止对手立即连五，并评估吃子与回吃，避免不断向车的攻击线上白送棋子。电脑使用三层算法：子力与连线及交换评估、带 Alpha-Beta 剪枝的对抗搜索、在搜索边界继续计算吃子和强制防守的静态搜索。部署按照剩余棋池中各棋种的真实数量计算期望值；已抽出的棋子按确定棋种计算，不偷看随机结果、不额外抽子。

| 难度 | 常规搜索上限（双方各走一次算两层） | 吃子延伸上限 | 每步搜索时间预算 |
| ---- | ---------------------------------- | ------------ | ---------------- |
| 简易 | 3 层 | 2 层 | 约 0.45 秒 |
| 标准 | 5 层 | 3 层 | 约 1.6 秒 |
| 困难 | 7 层 | 4 层 | 约 4.5 秒 |

搜索采用迭代加深，到预算时使用上一轮完整结果，实际深度取决于局面、随机分支和设备性能。为控制移动端耗时，普通候选有宽度限制，并缓存已算出的局面；立即获胜及强制防守在限制候选之前检查全部合法行动。基础候选评估和线程启动会产生少量额外耗时，以上不是硬实时承诺。困难会计算更多后续攻防，但不是穷尽所有走法的完美棋手。

电脑在独立 Web Worker 内计算，思考时锁定玩家输入，重开或切换对局模式会取消旧计算。金圈提示对方下一手可成五的位置，选中棋子会显示该棋子的走法。两种棋盘均可单人或同屏游玩，切换模式需要确认重开。

本机棋局每次行动后自动保存，包括抽出尚未部署的棋子；刷新重放原规则恢复，不会重抽。损坏或非法的存档不会进入游戏。浏览器禁用存储时页面会明确提示。当前只保留最近一局，不含账号或跨设备同步。
