# H5 提示广告开关与安全区复验

独立网页未配置广告时继续免费查看战术提示，使用提示后本题最高一星。宿主明确启用广告时，通过可选 `SmallGamesRewardAds` 请求；只有明确完成才能展开提示。取消、失败、超时、切换页面和前后台变化不会授权迟到回调。

本地使用 Node 24.21.0、Chrome 155、手机尺寸触屏模拟。规则与奖励检查 30 项通过，独立 HTTP 房间检查 1 项通过。没有运行或冒充真实广告、TapTap 真机验收。

`node build.js` 后运行 `node pavilion-check.mjs`：18 个流程全部通过，生成 107 张实际运行截图。两个安全区样本均通过，保留了 `.home-note` 的完整可见性断言：
