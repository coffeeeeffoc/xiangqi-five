# 象五子棋首版实现计划

**目标：** 手机浏览器可玩的双人同屏对局，完整验证抽子、部署、移动、吃子及五连胜利。

**架构：** 原生 HTML / CSS / JavaScript，规则独立为纯数据模块，DOM 负责交互，Node 内置测试与静态服务。零第三方依赖。

## 规则决策

- 9 列 × 10 行，空盘开始，红方先手。双方各 16 子：车2、马2、相/象2、士2、帅/将1、炮2、兵/卒5。
- 每回合移动一枚己方棋子，或从剩余棋子中等概率抽取一枚实体棋子后放置。抽子锁定本回合为部署，不允许取消重抽；放置到任意空点后结束回合。
- 五连包含横、竖、两种斜线，长度至少五枚，种类不限。无将军/将死/照面规则，帅将可以被吃，吃子不回池。
- 用户已确认自由部署版：取消九宫和相象不过河限制；保留蹩马腿、塞象眼、炮隔一子吃子。红向上、黑向下，兵卒过中线后可横走，不可后退。
- 双方共享一台设备。先完成核心玩法；联网、人机、账号与自动重复局面判和不在首版范围。无可用合法行动时判和。

## 实现与检查

1. `game.js`：集中状态转移与合法性校验。`game.test.js`：Node 内置测试覆盖所有走法、阻挡、抽取锁定、数量守恒和四向五连。
2. `index.html`、`style.css`、`app.js`：宣纸棋盘、双方棋池、回合状态、移动提示、抽子展示、走子记录、规则弹窗与新局确认。使用真实按钮支持键盘，窄屏不横向溢出。
3. `server.js`、`package.json`、`README.md`：零依赖运行入口、规则说明和移动端访问方式。
4. `npm test` 验证引擎；启动本地服务并在浏览器检查抽子→落子→换手→移动，以及窄屏布局和规则弹窗。

当前目录无 Git 仓库，不创建远程、不发布。规则有更改时同步文档、引擎和测试。
