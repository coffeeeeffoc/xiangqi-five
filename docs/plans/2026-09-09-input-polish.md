# 交互修正与验证

- 没有合法移动且仍可部署时，直接点击空位完成随机抽子与上场；保留先抽子查看的入口。同屏与房间共用规则，目的地检查在抽子之前完成，非法点击不消耗棋池。
- 棋盘上方独立显示放大、缩小、恢复大小及当前比例；放大不会把恢复入口挤出棋盘区域。支持 100%–300% 双指缩放和平移，恢复重置比例和滚动位置。
- 双指手势期间及结束后短暂抑制点击，防止误落子；单指继续使用浏览器原生滚动。
- 用户界面的“手记”统一改为“对局记录”。
- 象棋盘显示楚河汉界，五子棋盘不显示；标识不改变过河或后退规则。

验证：11 项 Node/真实 HTTP 测试通过。浏览器双方首次直接落子正确换手；缩放/恢复入口可用；Chrome 双触点输入从 100% 放大到 180%，平移后滚动位置从 (138,153) 到 (178,183)，棋子数保持 0；恢复回 100%。切换五子棋盘后为 225 点且无河界标识。双指验证使用浏览器触摸模拟，尚未做真实手机验收。
