# 提示与悔棋回调修正

沿用现有竖屏棋盘与纸色界面；横屏、小屏继续使用现有适配。`concept.png` 是本次局部修改的效果图，H5 将「获取提示」和「悔棋·免费1次」并排放置。原生 Canvas 的抽子按钮占一行，提示与悔棋占下一行，保证触控热区。

- 本设计替代上一版 computer-hints-2026-10-18 中“先分析后广告”的流程。现在必须先收到完整观看回调，再返回前台，才开始分析。分析成功后高亮起点/落点并保留说明；同回合已获权益可重看或免费重算。
- 取消、不可用、分析失败均保留明确提示。已看完广告但分析失败时，本回合再次获取提示不要求重看。
- 广告触发 Hide/visibilitychange 不取消该次请求；关闭回调先到、Show 先到均支持。主动退出当前页面或销毁实例仍取消请求，迟到回调不能给新棋局发奖励。
- 人机对局每局首次成功悔棋免费；免费是否已用随原有 v1 存档保存，旧存档默认为未用。之后每次只接受 completed 广告回调；没有广告能力也不能无限免费悔棋。
- 悔棋撤销玩家上一手及电脑随后的应对，回到玩家可重新落子的状态。部署悔棋保留当时抽到的棋子，不能借此重抽。当前已抽子、电脑回合、终局及没有可撤回动作时按钮不可用；不改变同屏、练习、联机规则。
- 悔棋广告未完成或失败显示：`未成功获得悔棋次数，悔棋失败`。仅成功撤回才更新棋局和免费额度。

验收使用规则测试、共享广告控制器测试、H5 实际 Worker 和手机触屏模拟、原生 Canvas SDK 回调模拟；真机商业广告播放另行验收。
