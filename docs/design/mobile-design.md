# 象五子棋移动端设计

先制作 [四页面效果图](mobile-concept.png)，再据此实现页面。奶油色背景、珊瑚红与薄荷绿双方、木色棋盘、圆角描边和有表情的棋子贯穿全流程。首页使用 SVG 双棋子插画，游戏棋子的汉字保持清楚，小脸位于下方。

| 页面       | 常驻内容                                             | 小入口与下一步                                 |
| ---------- | ---------------------------------------------------- | ---------------------------------------------- |
| 首页       | 标题、双棋子插画、开始、快速练习；已有棋局时显示续局 | 玩法小课堂、设置                               |
| 玩法选择   | 单人挑战、双人同屏、好友对弈、战术闯关               | 集成版临时房间放在更多玩法                     |
| 准备       | 对手、棋盘、电脑难度、开始                           | 已有棋局更换模式或棋盘，先进入重开确认页       |
| 玩法小课堂 | 部署、走子、同色连五三步图解                         | 七种棋子走法；更细规则折叠                     |
| 对局       | 棋盘、双方回合、抽子 / 移动                          | 更多、放大 / 恢复；练习只留目标和提示入口      |
| 对局小口袋 | 记录、棋池、规则、设置、重开                         | 各自进入独立页面，返回保留棋局                 |
| 练习与结算 | 选题、星星进度；结算展示结果与下一步                 | 提示、分享各自按需打开                         |
| 好友对弈   | 建房 / 加入、准备、棋盘、结果                        | 排行与昵称使用页面；集成服务和临时房间分别保留 |

## 触屏交互

- 点空点直接随机部署，或先抽子再点空位；已抽棋子必须完成部署。
- 点己方棋子，合法移动绿点、吃子红圈在棋盘内出现。再次点同子取消走子选择。
- 部署弹跳、棋种专属移动轨迹、吃子星光给出反馈；减少动态效果时跳过动画。
- 游戏返回首页、查看说明 / 记录 / 棋池、浏览器返回都保留状态。单机棋局含待落棋子自动保存，练习保留原棋局。
- 主入口和底部操作使用至少 44px 触控区域。大棋盘可双指或放大镜放大；双指取消不会触发落子。
- 竖屏棋盘居中、操作靠近下方；横屏棋盘右置、状态与操作左置。安全区通过 CSS 环境变量处理。
