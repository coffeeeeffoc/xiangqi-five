# 人机对战广告提示与棋力提升

> 历史初版方案。后续已改为“获取提示”、先广告后分析，广告导致的隐藏保留请求，首次悔棋免费并保存状态。以下旧流程用于保留设计演进，当前广告规则与证据见[最终修复记录](../h5-ad-open-timeout-2026-10-19/README.md)。

沿用现有竖屏木色棋盘和页面关系。主页、选关不变；人机游玩页的操作区增加「看广告·提示」（无广告渠道为「分析提示」），只在玩家回合可用。完成后在棋盘标出起点/落点，并用一句话说明连五、防守、吃子或布局目的。提示不替玩家落子，同一回合可重看；抽到具体棋子后仍保留本回合授权，可重新分析而不重复播放广告。

先分析、后请求广告：没有合法建议、明确已无法阻挡下一手连五或分析失败时不播放广告。只接受广告完成回调；取消、失败、切后台或离开页面时取消未完成流程。已完成授权在当前回合保留；落子、重开或更换对局后失效。广告播放和分析期间锁住棋盘输入，保留返回/暂停路径。

对手与提示共用规则搜索。保留立即获胜/全量防守检查和真实棋池概率，加强连续强制威胁搜索、候选排序与搜索复用。普通对手保持难度分档，提示采用独立更高预算；给出具体推荐动作及可证实的简短原因，不把启发式分数称为必胜。

验证：确定性战术局面覆盖立即获胜、唯一防守、吃子拆线、连招、随机与已抽棋子、强弱对比和输入不变；手机触屏验证广告完成/取消/失败/迟到回调、同局面重看、抽子后重分析、落子清除、暂停返回、新局及窄屏。原生 SDK 使用模拟回调验证，真实平台广告与真机性能另行验收。
