# 首页与分享调整 · 2026-10-18

沿用[山间棋亭效果图](../pavilion-concept.png)和原有竖屏布局。左上角图标仅避让实际刘海/状态栏加 4px，设置在其下方；中央标题仍避让右侧胶囊。无全屏按钮。

左上紧凑图标复用已选定的五子连线 Logo 素材。加载页与首页中央 Logo 的接入属于另一项独立改动；本文截图与提交验证仅包含本次首页、分享及安全区调整。

首页、普通对局分享游戏入口，战术练习分享当前关卡。公开链接移除开发参数、服务地址与身份凭证，分享不可用时支持手动复制。

独立 `node build.js` 默认关闭旧房间；显式 `--with-service` 才开启独立房间。托管竞赛构建始终关闭旧房间，避免旧邀请、旧会话与轮询发起请求。无服务包从 HTML 首屏隐藏 PK 与全站榜入口。

已验证：7 项关卡/分享与无服务构建单测，8 个实际触屏战术练习、失败重试、分享取消/手动复制、普通棋局存档隔离；305×568、844×390、1280×800 的键盘与页面往返；桌面和触屏下工具、说明、历史、重开及返回棋盘。共享安全区覆盖普通浏览器、模拟宿主、横屏和 iframe。
